# 完整混合 Prompt 示例

本示例用于展示英文叙事在前、tag block 在后的组装方式，以及复杂情绪、嵌套画面和工作流特殊语法的处理方式。

它不是固定模板，不是默认 tag 词库，也不证明其中所有 tag 都已验证。实际请求必须根据当前自然描述重新查询、验证和筛选。

- `{{warm color theme}}` 是用户或工作流提供的特殊语法，不作为 Danbooru tag 验证。
- `mari (blue archive)` 和 `blue archive` 只属于本示例的角色与作品锚点，不应自动添加到其他请求。
- `>\\\_<` 按特殊表情写法原样保留，不把它当作普通 tag 处理。
